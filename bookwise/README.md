# Bookwise

A book management application with user authentication, book discovery, and admin panel.

## Project Structure

- **HTML Files**: Main pages for the application
  - `index.html` - Homepage with book grid
  - `book.html` - Book detail page
  - `auth.html` - Login/Signup page
  - `dashboard.html` - User dashboard
  - `admin.html` - Admin panel

- **CSS**: Stylesheets
  - `css/style.css` - Main stylesheet

- **JavaScript**: Application logic
  - `js/firebase-config.js` - Firebase configuration
  - `js/auth.js` - Authentication logic
  - `js/books.js` - Book data management
  - `js/dashboard.js` - Dashboard functionality
  - `js/admin.js` - Admin functionality
  - `js/utils.js` - Utility functions
